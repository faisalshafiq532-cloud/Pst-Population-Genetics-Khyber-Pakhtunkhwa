# Data directory

This directory contains the data files required for the analyses included in this repository.

## SSR genotype data

### `SSR_PK-data.xlsx`

This workbook contains the SSR genotype dataset for 144 single-urediniospore-derived isolates of *Puccinia striiformis* f. sp. *tritici* collected from seven districts of Khyber Pakhtunkhwa, Pakistan.

The dataset contains the isolate metadata and genotype information for the 17 SSR loci used in the population genetic analyses.

The original worksheet names and data structure have been retained to maintain compatibility with the accompanying R scripts.

## STRUCTURE directory

The `STRUCTURE/` subdirectory contains files associated with the population structure analysis and visualization workflow.

See the README file within that directory for details.
